Política de privacidade

Agenda · atualizada em novembro de 2026

A Agenda é um aplicativo pessoal que mostra, numa tela só, as reuniões do Outlook, os compromissos do Google Agenda e as tarefas do Google Tasks do próprio usuário.

Quais dados o app acessa

  • Google Agenda: lista de agendas e eventos, para exibir, criar, editar e excluir compromissos.
  • Google Tasks: listas e tarefas, para exibir, criar, concluir e excluir demandas.
  • E-mail da conta Google: só para mostrar com qual conta você está conectado.
  • Calendário publicado do Outlook: lido no modo somente leitura, a partir do link configurado pelo próprio usuário.

Onde os dados ficam

O app não tem banco de dados nem servidor que guarde seus dados. As informações são lidas direto do Google e do Outlook e ficam salvas apenas no navegador do seu dispositivo (cache e configurações), para o app abrir rápido e funcionar offline.

A "ponte" (um Cloudflare Worker do próprio usuário) só repassa as requisições: busca o calendário do Outlook e troca e renova os tokens de login do Google. Ela não armazena eventos, tarefas nem tokens.

Compartilhamento

Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como remover o acesso

  • No app, vá em Ajustes → Apagar dados deste navegador.
  • Para revogar o acesso ao Google, vá em myaccount.google.com/permissions, escolha Agenda e clique em Remover acesso.
